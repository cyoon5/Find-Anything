# Find-Anything

A full-stack document management and file exchange platform built on the MERN stack. Features user authentication, document sharing, commenting, review workflows, and containerized development environments.

## Tech Stack
- **Frontend:** React, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js (REST APIs, JWT Authentication)
- **Database:** MongoDB
- **Testing & DevOps:** Jest, Docker, Git/GitHub

## Key Features
- **User Authentication & Authorization:** Secure registration, login, and role-based dashboard access.
- **Document Management:** Upload, categorize, and retrieve shared documents and review data.
- **Automated Testing & Containerization:** Unit and integration test coverage via Jest; multi-container Docker setup for consistent dev environments.
